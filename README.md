# Список задач (TodoList)

Веб-приложение для управления задачами с возможностью указания даты и времени выполнения.

## Как запустить

Откройте файл index.html в любом браузере.  

## Реализованный функционал

- Добавление задачи с текстом и датой/временем выполнения
- Удаление задачи
- Отметка задачи как выполненной
- Фильтрация по статусу: все, активные, завершённые
